## 1. Safe Testing Environment & Rules

- **Target:** Local Flask instance (`http://127.0.0.1:5000/`) running via isolated PyTest SQLite database (`tmp_path/test_security.db`).
- **Accounts:** Dedicated local test accounts (`syasya_test1`, `syasya_test2`) only.
- **Compliance:** No external scanners, no network traffic outside localhost, and request loops capped at 20 requests or fewer per test.
